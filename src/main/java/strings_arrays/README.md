# strings_arrays

Topic: **Strings & Arrays** — STEP Semester 3, Session 1

## Folder layout (per STEP spec)

- `class_problems/`     — problems solved live in the lab session.
- `assigment_problems/` — take-home assignments. *(Spelling preserved per the STEP GitHub guide.)*

## Session 1 — class problems

| File | What it does |
|------|--------------|
| `ReverseString.java`        | Reverses a string using a two-pointer swap. |
| `PalindromeCheck.java`      | Checks if a string is a palindrome (ignores case and non-alphanumerics). |
| `LargestInArray.java`       | Finds the largest element in an `int[]`. |
| `SecondLargest.java`        | Finds the second-largest *distinct* element in an `int[]`. |

## Week 1 Assessment — class problems

| # | File | What it does |
|---|------|--------------|
| 1 | `RockPaperScissors.java`     | Plays 5 rounds of RPS vs. computer, prints per-round results + scoreboard with win %. (`playRound`) |
| 2 | `PalindromeChecker.java`     | 3-approach palindrome check (iterative + recursive + array-reversal). All three must agree. |
| 3 | `BmiCalculator.java`         | Computes BMI for a 10-person team, classifies Underweight/Normal/Overweight/Obese, prints a table. (`getBmiStatus`, `printWellnessReport`) |
| 4 | `FirstNonRepeatingChar.java` | Finds the first character that appears exactly once in the input, or reports none. (`findFirstNonRepeatingChar`) |
| 5 | `ReverseCustomerName.java`   | Returns the reverse of a customer's name without mutating the original. (`reverseCustomerName`) |

## Session 1 — class problems

| File | What it does |
|------|--------------|
| `ReverseString.java`   | Reverses a string using a two-pointer swap. |
| `PalindromeCheck.java` | Checks if a string is a palindrome (ignores case and non-alphanumerics). |
| `LargestInArray.java`  | Finds the largest element in an `int[]`. |
| `SecondLargest.java`   | Finds the second-largest *distinct* element in an `int[]`. |

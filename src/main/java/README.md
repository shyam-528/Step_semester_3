# src/main/java

This is the empty Java project skeleton for the **develop** branch.

Per the STEP GitHub Structure Guide:
- This branch holds **no solution code** — only the empty IDE-style project structure.
- All live coding is done in a `feature/session_<n>` branch created *from* `develop`.
- Topic folders (e.g. `strings_arrays/`, `oop/`, `recursion/`) are added inside `src/main/java/` on the feature branch.

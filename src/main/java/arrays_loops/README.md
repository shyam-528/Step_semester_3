## Session 2 — class problems

| # | File | What it does |
|---|------|--------------|
| 1 | `DuplicateSeats.java`      | Scans an `int[]` of seat numbers for duplicates using nested loops (no Collections). (`checkDuplicateSeats`) |
| 2 | `TypingAccuracy.java`      | Compares two strings char by char; reports match count, accuracy %, and first mismatch position. (`checkTypingAccuracy`) |
| 3 | `TrafficSignalStreak.java` | Finds the longest run of identical consecutive signal chars ('R','Y','G'). (`findLongestStreak`) |
| 4 | `InventoryBalancer.java`   | Compares totals of two sections (Balanced / Not Balanced) and locates the single highest quantity. (`analyzeInventory`) |
| 5 | `WordLengthProfiler.java`  | Splits a review into words and counts Short (1-4) / Medium (5-8) / Long (9+) buckets. (`classifyWordLengths`) |
